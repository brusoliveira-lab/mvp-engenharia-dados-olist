# Licença e atribuição dos dados

Este projeto utiliza o **Olist Brazilian E-Commerce Public Dataset**, publicado
pela Olist no Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

A página da fonte indica a licença **Creative Commons Attribution-
NonCommercial-ShareAlike 4.0 International (CC BY-NC-SA 4.0)**:

https://creativecommons.org/licenses/by-nc-sa/4.0/

O uso realizado neste MVP é acadêmico e sem finalidade comercial. O projeto
transforma e analisa os dados para fins educacionais, identifica a fonte e a
licença e não redistribui os arquivos CSV originais.

Esta nota trata da licença do conjunto de dados. Ela não altera nem substitui os
termos definidos pelos titulares da base.
